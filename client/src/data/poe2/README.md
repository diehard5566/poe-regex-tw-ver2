# POE2 繁中工具資料與驗收

## 路由與功能

| 路由 | 功能 |
| --- | --- |
| `/poe2/waystones` | 32 組包含／排除詞綴、任一／全部、個別詞綴整數門檻、階級、復活、收益、稀有度、汙染、玩家譫妄 |
| `/poe2/tablets` | 67 個獨立屬性、8 類碑牌、剩餘使用次數、稀有度、任一／全部 |
| `/poe2/relics` | 30 個獨立屬性、前後綴分欄、任一／全部／前後綴各至少一項 |
| `/poe2/vendor` | 39 個常用屬性、最多 5 組 AND/OR 條件、品質／插槽／需求與物品等級／稀有度／汙染／種類 |
| `/poe2/items` | 34 分類、941 筆分類內屬性記錄、基底、數值、前後綴及物品條件 |

全部在前端計算。Items 與其他新頁採路由 lazy import，沒有新增套件、runtime 第三方 API 或後端端點。

## 來源與範圍

- 核對日期：2026-10-03。
- 官方繁中詞綴：https://pathofexile.tw/api/trade2/data/stats ，僅取 `explicit` / `sanctum` 文字，不把交易 `pseudo` 加總屬性當物品文字。
- 官方基底：https://pathofexile.tw/api/trade2/data/items 。只保留官方清單中存在的基底。
- 候選分類參考 veiset/poe.re `5d07d01`。數值門檻參考上游「欄位片段 + 最小值數字規則 + %」策略；沒有搬上游程式碼、optimizationTable、英文詞序匹配或商業服務。來源授權／資料使用條款仍需發布者確認。
- 各屬性文字與官方 stat ID 保留在 JSON；縮短搜尋片段由本專案獨立產生，須在整份官方詞綴語料中唯一，否則退回整行匹配。
- 複合詞綴拆成個別官方屬性，不暗示為完整工藝模組或保證詞綴數量。分類本身不保證每個基底能生成所有候選。
- 無法確認的翻譯列在 `audit.json`，不自動改寫「增加／減少」「更多／更少」或反轉數字正負號。
- 換界石冷卻恢復與 3 個聖物減少詞綴已由官方公開交易物品的 description 確認：交易模板使用相反方向的文字，實際物品為「更少／減少」。`display-overrides.json` 保留模板、顯示文字與數值範例；不是全域轉換正負號。
- `property-samples.json` 保留去識別化的官方公開物品 properties 與詞綴樣本。換界石實際欄位是「可用的復活數」「怪群大小」「怪物效能」，不是交易 filters API 的標籤。
- 碑牌使用次數文字參考 https://poe2db.tw/tw/Abyss_Tablet ：「剩餘10次使用次數」。
- 換界石名稱及階級參考官方 items 和 https://poe2db.tw/tw/Waystones 。
- 依使用者指示，品質、等級、汙染、稀有度和種類欄位採 POE1 繁中格式；教學來源 https://forum.gamer.com.tw/C.php?bsn=18966&snA=140339 。沒有直接照抄其數值 regex。
- 符文插槽以 POE2 上游的 `S` 表示方式配合中文「插槽:」欄位，不能替代 POE1 的 RGB 或連線篩選。

## 數值規則

不四捨五入或截斷。門檻以文字中的 `#` 順序對應，支援 -9999～9999 整數；兩欄空白時可匹配小數，填門檻時不接受小數。詞綴的單邊空白表示該方向不設限，不再補成 ±9999。階級、復活、等級及碑牌次數仍按各欄位支援範圍限制。預設一般文字；勾選「進階詞綴文字」時，`25(20-30)` 以第一個 25 為實際值，括號範圍不作為比較值。兩種模式分開產生，不再替每個數字附加可選括號相容式。最小＝最大才是指定數值；只填最小表示至少該數值。

商店／物品品質與換界石收益共用短數字產生器。只有最小值時，使用上游式短規則，例如 50% 為 `"物品稀有度.*([5-9].|\d..)%"`；適用非負整數百分比，不向下取整，較長位數也可匹配。填最大值時仍採完整數字邊界，避免 150% 被當成 50%。

比對的上游實作（`5d07d01`）：
- `shared/core/regex/GenerateNumberRegex.ts`：按位數產生最小值／範圍片段；此處保留精確最大值與負數，未沿用超出兩位數便退回最低值的 fallback。
- `poe2/src/pages/vendor/VendorResult.ts`：上游品質只有有無勾選；本專案的品質數值是延伸條件。等級用欄位前綴及數字邊界，而非整行通用解析。
- `poe2/src/utils/SelectedOptionRegex.ts`、`shared/core/item/ItemOutput.ts`：上游利用數字位置與進階括號定位。本專案提供一般／進階切換，進階模式保留括號終點，不能把另一個數字當成本欄數值。

多行換界石只限制第一行的第一個數值。品質 0 仍要求品質行存在；未提供品質行不等同匹配 0。需求等級依 `等級:` 行，不以 `物品等級:` 代替。

超過 250 字顯示錯誤並停用複製，不自動截斷；使用者需減少條件。收藏機制暫不加入。

## 中文數值短片段

`numeric-templates.json` 收錄 391 個數值模板。離線腳本僅裁短數字前後的中文，不刪除或交換任何 `#`；以完整官方語料檢查唯一性，也將固定數字當作潛在衝突。無法安全縮短時保留完整上下文。數值條件不再一律退回完整模板。

例如跑速 30% 的上游 `30% i.+mov` 是固定數字，不是 ≥30%。本專案一般模式最小＝最大＝30 為 `"^增加\+?30%移動速度$"`。保留頭尾是為了排除召喚物跑速，以及帶固定 25% 的額外效果詞綴，不能只以最短字數為目標。

## 維護命令

```sh
# 重建碑牌／聖物／商店／物品候選；先固定 upstream commit，再人工 review diff
python3 scripts/build-poe2-data.py /path/poe.re /path/stats.json /path/items.json
# 只重建數值短片段；build-poe2-data.py 也會自動執行此步
python3 scripts/build-poe2-numeric-templates.py /path/stats.json
cd client
npm run build
```

重建腳本不更新已人工整理的 `waystones.json`；更新時需同步核對核對日期和排除清單。不要讓網站訪客直接觸發來源爬取。

## 仍需實際遊戲驗收

1. 正常／進階複製的繁中物品：詞綴、正負值、小數、括號範圍。
2. 包含、排除、AND/OR 多組條件、前後綴模式、數值上下界與 250 字邊界。
3. POE1 沿用欄位在 POE2 的實際文字，包括需求等級、符文插槽和物品種類。
4. 短 regex 在整件物品（包含名稱、基底、固定詞綴）上是否誤中；語料交叉測試不是遊戲內驗收。

尚未提供：來源不一致的詞綴；用魔法物品名稱推斷空前後綴／相似基底；收藏、雲端帳戶／設定檔；交易站／價格／上游廣告整合。
